How it was built

Ten classmates and faculty each built a generative AI project. Five of them did text-to-image with Stable Diffusion, and those gave the best results, so we merged their best ideas into one model and fixed what was missing.

  1. Your prompt + a styleStyle presets add tested wording and a list of things to avoid.
  2. Stable Diffusion 1.5Half-precision weights, attention slicing and VAE tiling, so it fits on a free Colab GPU. Falls back to CPU.
  3. CLIP scoringEvery candidate is compared with your words. The best match is shown first.
  4. Safety checkThe built-in safety checker stays on. Flagged images are blacked out.

Memory-efficient engine

A half-precision pipeline with attention slicing and VAE tiling. It became the core of the engine.

Measuring accuracy

The original version compared two sentences. Now the prompt is compared with the actual image using CLIP.

CPU fallback

A simple prompt-to-file generator that also runs without a GPU, kept as the fallback.

Interactive controls

An interface with tunable sliders from a text-generation project shaped these controls.
